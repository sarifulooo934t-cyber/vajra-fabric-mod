# Vajra - Indra's Thunder

A Fabric mod for **Minecraft 1.21.11** (Fabric Loader + Fabric API).

## What it adds

- **Vajra Ore** - a new crystal ore that generates underground in the Overworld (y -63..40).
- **Vajra Ingot** - smelt or blast Vajra Ore, or mine the Block of Vajra back into ingots.
- **Vajra tool set** - sword, pickaxe, axe, shovel, hoe (very durable, fast, high damage).
- **Vajra armour set** - helmet, chestplate, leggings, boots.
- **The Vajra** - Indra's thunderbolt. Right-click while looking at a block to call down a
  real lightning bolt where you aim. Short cooldown between strikes.

## Crafting

- Block of Vajra: 3x3 of Vajra Ingot.
- Tools: Vajra Ingot + sticks (vanilla tool shapes).
- Armour: Vajra Ingots in the vanilla armour shapes.
- The Vajra: Vajra Ingots + a Nether Star + a stick.

## Building

```bash
./gradlew build
```

The finished jar appears in `build/libs/`.

## Installing

1. Install Fabric Loader for Minecraft 1.21.11.
2. Put **Fabric API** and this mod's `.jar` in your `mods` folder.
3. Launch.
